Parallel Problem Solving Lab

A hundred agents work on the same rugged problem. Each round, an agent copies the best-performing contact it can see, and if none of its contacts is doing better, it tries changing one thing about its own solution. Conditions differ only in who can see whom. Run a contest and watch which network finds the better answer, and when.

How the model works

1 · The problem

An NK landscape: N yes/no choices, so 2N possible solutions. Each choice’s payoff depends on K other choices. K = 0 gives one smooth peak; higher K gives many local peaks. Scores are shown as a share of the landscape’s best solution raised to the 8th power, as in the paper, so most random solutions score near zero.

2 · The start

Every agent gets a random solution. Within a contest, every condition starts from the same solutions on the same landscape, so differences come from the network alone.

3 · Each round

With probability equal to velocity, an agent checks its contacts. If one is doing better, it copies the best of them. With an error rate e, each differing choice fails to copy with probability e; if the resulting blend is worse, the agent keeps its own. Otherwise the agent flips one random choice and keeps the change only if it helps.

4 · What we measure

The average score across all agents, and how many distinct solutions remain. The paper’s core result runs through the second number: efficient networks spread good ideas fast and also wipe out the variety needed to find better ones.

Modeling choices not fixed by the paper. All agents update at once from the previous round’s positions. An agent whose contacts score the same as it does explores rather than copies, which reproduces the “bouncing” the authors describe in fully connected networks. Small-world networks start from a ring where each agent talks to its two nearest neighbours on each side; a shortcut rewires one tie to a random distant agent, and rewirings that would cut someone off are skipped, as in the paper. Random networks are not forced to be connected, so sparse ones can split into isolated groups (the readout reports the number of components). Results from 25 or 50 landscapes will not match the paper’s figures exactly but should show the same patterns.
